# AI Control Plane — B09: Provider-Neutral Single-Agent Tool Loop

## What shipped

One agent loop connecting the existing AI chat to Sirkit's tool control
plane, default-deny end to end:

- **`app/lib/agent/contracts.ts`** — provider-neutral contracts
  (AgentRunRequest/Context/Budget, AgentStep, AgentToolCall/Result,
  AgentRunEvent/Result, ProviderContinuation, ProviderAgentAdapter,
  AgentToolInvocationGateway). No provider SDK types anywhere outside the
  adapters.
- **`app/lib/agent/adapters.ts`** — OpenAI (Responses API, FLAT function
  tools, `store:false` manual state, `include:
  ["reasoning.encrypted_content"]`, every `function_call.call_id` answered
  by an exact `function_call_output`, `parallel_tool_calls:false`) and
  Anthropic (verbatim assistant `tool_use` blocks, immediately followed by
  user `tool_result` blocks with exact `tool_use_id` and `is_error`,
  `disable_parallel_tool_use`). Continuation state is opaque + transient.
- **`app/lib/agent/provider-tools.ts`** — strict schema conversion
  (additionalProperties:false everywhere, full required lists, nullable
  optionals), collision-checked reversible provider-name ↔
  `{toolId, version}` mapping, current provider shapes, parity report.
- **`app/lib/agent/loop.ts`** — bounded deterministic loop: step/call
  budgets, per-tool timeout + run deadline, AbortSignal propagation,
  identical-call cycle detection (tool id/version + canonical arg digest),
  proposal single-flight (a retry can never double-issue), sequential
  deterministic multi-call handling, bounded redacted JSON results, no
  fallback, no recursion.
- **`app/lib/agent/gateway.ts`** — reads through the REAL unweakened
  B05/B05.1 `ReadToolInvocationService` (fresh discovery + full resource
  verification per invocation); proposals through the separate
  `ProposalInvocationService` (compile all-or-nothing → seal → digest-
  pinned artifact; mutates nothing; kicad deletes without pin data fail
  closed). Mutation/destructive/release/view-session classes refuse
  outright.
- **`app/lib/agent/context.ts`** — smallest truthful run-context
  assembler + the documented `LOCAL_ONLY` actor factory (application-owned;
  request bodies and models can never supply actor/role/capabilities/
  authority/revision). Malformed snapshots degrade tool availability.
- **`app/api/chat/route.ts`** — versioned NDJSON event protocol
  (run_started, text_delta, tool_started, tool_finished, proposal_ready,
  warning, run_failed, run_completed; every line carries v/runId/seq).
- **`app/page.tsx` send()** — protocol consumer: scope-gated event
  application (B07.4/B07.5 semantics preserved — late events write nothing
  into a replacement project), truthful tool activity lines, proposal_ready
  routed into the EXISTING Apply-exact-proposal review boundary, classified
  provider failures, chat persistence unchanged (no raw tool payloads).
- **`AGENT_SYSTEM_PROMPT`** (prompts.ts) — one provider-neutral behavioral
  prompt (tool results are data; proposals-only edits; no invented
  authority; release unavailable).
- **Registry** — `sirkit.schematic.inspect` finally bound (new pure
  accessor `app/lib/engineering/schematic-read.ts`, allowlisted read
  binding); NEW `sirkit.schematic.propose-tier1-edit` (bound-proposal);
  8 tools agent-exposed (see the manifest); B04 zero-exposure invariants
  replaced by the exact-set + activated-binding tripwire.
