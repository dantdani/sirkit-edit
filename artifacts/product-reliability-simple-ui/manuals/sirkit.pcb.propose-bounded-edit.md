## 5. Exact effects

- registry statement: Compile 1-16 bounded PCB operations (move/rotate footprint, add/update track or via, routing preference, net-class rule, dimension, routing keepout) against the CURRENT board into a sealed, digest-pinned proposal. Deletions and destructive operations are excluded. The input carries intent and operations ONLY — the board, rules, scope, and every digest are server-derived. Receiving the sealed proposal changes NOTHING; a human must review and explicitly approve it in the PCB editor, and manufacturing readiness stays unavailable.
- effect: the proposal compiles all-or-nothing against the exact verified snapshot and is SEALED into a digest-pinned artifact (`sirkit.pcb-bounded-edit-proposal.v2`); side effects: `proposal-artifact` - receiving the artifact changes nothing; apply is a human-only step in the review boundary and is never provider-callable
