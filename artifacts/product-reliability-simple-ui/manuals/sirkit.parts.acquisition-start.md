## 5. Exact effects

- registry statement: Start (or attach to) the durable acquisition task for catalog instances of ONE catalog part that have no eligible local revision: a worker retrieves the part's real KiCad symbol and footprint (and a pin table where an admitted source has one) from an ADMITTED CAD source only (the pinned official KiCad library; never an arbitrary URL), stores and hashes the bytes, parses and validates pins, pads, mapping, package and pin 1, and prepares a review package. Works without a PCB. Example input: {"componentIds":["kc-3a9f01","kc-3a9f02"],"requirement":{"mounting":"through_hole","packageCode":"DO-35"},"assetKinds":["symbol","footprint","datasheet"]}. NOTHING in the design changes; a PERSON sends the package for review, a reviewer approves and a different administrator publishes; only then is the replacement offered for the user's review. A published revision of the same part is reused without any download.
- effect: start: the durable component-resolution task is started or attached (idempotent on scope, principal, instances, requirement and schematic base); a worker slice later runs the local search (a published revision of the same part is REUSED, nothing downloaded), the admitted CAD sources, the parse and the validation, and stores the candidate; status: the task's public view is read.
