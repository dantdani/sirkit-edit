## 5. Exact effects

- registry statement: EXECUTION tool: add a dimension annotation measuring between two board points (horizontal, vertical or aligned), change an existing dimension's kind, offset or style (layer, unit, precision, text height, stroke), or remove one. Dimensions are documentation only (silkscreen or fabrication layers, never copper); the displayed value is derived from the points. Calling it never changes the board by itself — the server issues a one-shot grant bound to the current board revision, and the user's editor shows the exact change for the user to confirm; nothing is committed until they do. Name an existing dimension by its stable id (selection-inspect lists the dimensions the user selected; an executed result lists the ids it added); 1–16 edits; an update never moves the measured points (remove it and add a new one).
- effect: the call seals an execution intent against the verified board and MINTS a server-bound one-shot grant (`sirkit.agent-execution-grant.v1`) bound to the board revision, history head, lineage and DRC policy; NOTHING changes here - the user's editor tenders the grant: a preview the user confirms (`preview_then_confirm`), or the exact user-requested operation under `execute_explicit_tier1` (`execute_explicit`); the commit is one canonical transaction through CanonicalEditorSession (`pcb.dimension`), one undo entry
