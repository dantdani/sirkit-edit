## 5. Exact effects

- registry statement: Read a board's VIA facts only, in millimetres: every net that carries vias (name and count, so a net name can be resolved or truthfully found absent), the named net's vias (stable id, position, diameter, drill, layer span, locked, and the padstack each is bound to), and every via padstack the board has.
